# 《格物江湖錄：天理殘卷》v1.4.0 Windows 遊玩說明

## 啟動

1. 完整解壓縮 `GeWu_Tianli_v1.4.0_Windows_x86_64.zip`。
2. 執行 `GeWu_Tianli_v1.4.0.exe`。
3. 若 Windows SmartScreen 顯示未辨識的發行者，請確認檔案來自可信來源後再選擇執行。本測試包尚未購買商業程式碼簽章。

## v1.4.0 新增

- 第一至六章的 36 項證據與 24 場破局已補上章中主線推進、人物反應、A／B 路線差異與錯失後果；每章取得第 2、4 項有效證據時會出現章中轉折。
- 題名頁新增「作者連結｜Instagram」與「自由贊助｜支持創作」。兩者會使用系統預設瀏覽器開啟；贊助完全自願，不影響遊戲內容或結局條件。
- 全新動態題名頁與電影式雨夜構圖。
- 新遊戲加入四幕沉浸式劇情序引，可前後翻閱、略過，並可從題名頁重看。
- 序引階段會自動存檔；續玩依存檔返回原進度。
- 「減少動態」設定會停止持續推鏡與裝飾動畫。
- 另有一支獨立 45 秒、1080p 的開場影片供審片，本 Windows 遊戲包未嵌入該影片。
- 延續 v1.3.1 的九人肖像好感頁，以及柳照微、江濯月、蘇檀三條跨章情緣；其他人物維持同伴或師徒線。
- 舊存檔自動升級至 schema 8，章回、道具、好感、成就與結局圖鑑不會重置。

## 操作

- 滑鼠：對話、序引翻頁、調查、答題、選擇情緣與結局。
- `E`／`Tab`：格物卷。
- `R`：人物好感與情緣。
- `I`：行囊。
- `Esc`：序引略過、暫停與設定。
- `F11`：切換全螢幕。

## 存檔

遊戲自動保存主檔與備份檔。若希望保留多份進度，可在暫停選單匯出存檔文字。成就另存為永久檔，不會因新局或命運回折而消失。

## 已知限制

- 本包為 Windows x86_64 未簽章測試版。
- 已完成自動匯出、檔案格式與壓縮完整性檢查，但尚未在實體 Windows 10／11 電腦完成音訊裝置與 SmartScreen 人工測試。
- 獨立開場影片仍在審片階段，未包含於此遊戲包。
